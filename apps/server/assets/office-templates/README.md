# Empty Office templates

Templates for "New -> Word/Excel/PowerPoint/..." in the file browser.

- `new.docx`, `new.xlsx`, `new.pptx`: taken from the Euro-Office Document Server
  (`document-templates/new/de-DE`, AGPL-3.0, https://github.com/Euro-Office/DocumentServer).
- `new.odt`, `new.ods`, `new.odp`: generated from those with the `x2t` converter of the same
  image.
- `new.txt`, `new.csv`: only a UTF-8 BOM (so that umlauts are detected correctly).
