Self-hosted · Open source

Your folder stays your folder.

Synclet is a self-hosted alternative to Dropbox and OneDrive. The folder on your disk is the source of truth: Synclet indexes and serves the files that are already there, and never puts its own metadata inside. Throw the containers away and a normal folder remains.

Download for Mac Self-host with Docker

Mac app requires macOS 26 or later. Server runs anywhere Docker Compose does.

How Synclet treats your files

  • Nothing hidden in your folder

    No hidden directories, no extended attributes, no database files. Trash, versions and previews live in a separate metadata folder; the index lives in PostgreSQL.

  • Edit on disk or in Synclet

    Point Synclet at a folder you already have. Change files on the host, in the web app or from your Mac and iPhone: everyone sees the same thing.

  • Leave whenever you like

    Stop the stack, delete the containers. Your files are still a plain folder, organised exactly the way you left them.

Look before you download.

Press the space bar on any file for a QuickLook preview: photos, video, PDFs, Markdown and source code open right in the browser. Thumbnails and previews are generated in the background and stored outside your folder.

Shared folders, and the NAS you already own.

Create a team folder for the family or the office, mount an SMB or NFS share as external storage, and decide per user or group who may read or write. Every space is still a normal folder on disk.

Install

Up and running in five minutes.

You need a machine with Docker and Docker Compose, and a folder with your files (or an empty one).

  1. 1. Download two files

    No checkout needed: the images are prebuilt for amd64 and arm64.

  2. 2. Point it at your folders

    Edit .env:

    The meta and team folders must exist before the first start and be writable by PUID:PGID.

  3. 3. Start the stack

    Open http://localhost:8080 and complete the setup wizard. The username you choose is the folder name below SYNCLET_DATA; an existing folder with that name is adopted, and its files appear right away.

    Prefer to build from source? Clone the repository and add -f deploy/compose.build.yml, see the README.

  4. 4. Put it on the internet

    Automatic HTTPS: set SYNCLET_SITE_ADDRESS to your domain, SYNCLET_PORT=80, SYNCLET_TLS_PORT=443 and SYNCLET_PUBLIC_URL; the bundled Caddy fetches a Let's Encrypt certificate.

    Behind your own reverse proxy (nginx, Traefik, Nginx Proxy Manager): keep the defaults, set SYNCLET_PUBLIC_URL and put the proxy's address into SYNCLET_TRUSTED_PROXIES. Its read timeout must be longer than 25 seconds for live updates.

  5. NAS and other disks

    Every folder mounted below /storage becomes a space. Add it to the server service and, read-only, to the worker in compose.yml (commented examples, including an SMB/CIFS volume, are in the file). For network shares, switch the space to scheduled scans in the admin area. Then assign users or groups to the space.

FAQ

Questions, answered.

What happens to my files if I stop using Synclet?

Nothing. They are a normal folder on your disk and stay exactly as they are. Synclet keeps its index in PostgreSQL and its trash, versions and previews in a separate metadata folder. Removing the containers (even with their volumes) leaves your files untouched.

Do I need the apps?

No. The web app does everything in the browser: upload, preview, search, share, restore from the trash. The Mac and iPhone/iPad apps add integration with Finder and the Files app, offline folders and background uploads.

How do backups work?

Back up your files folder (and team folders) with any tool you like: they are plain files. To keep trash, versions, users and share links too, also back up the metadata folder and the database (for example with pg_dump).

Can I use my NAS or an SMB share?

Yes. Mount it below /storage as a bind mount or as a Docker CIFS/NFS volume and it shows up as a space. Network file systems don't report changes reliably, so Synclet scans them on a schedule you set. If the share goes offline, the space is marked unavailable; nothing is deleted.

Multiple users and shared folders?

Yes. Every user gets a personal folder. Admins create team folders and groups and grant read or write access per user or group. Public share links work for files and folders.

Is there an app for Windows or Android?

Not yet. Windows and Android apps are coming later. Until then, use the web app in any browser.

Is it free? What's the license?

Synclet is free and open source; the code is on GitHub. It is released under the MIT license.

How are updates done?

Set SYNCLET_VERSION in .env to the new release, then run docker compose pull and docker compose up -d. The server migrates the database on start. Downgrading after a migration is not supported, so back up the database before updating if you want a way back.

How secure is it?

Passwords are stored as Argon2 hashes and sign-ins are rate-limited. Single sign-on works with OIDC (with PKCE) or a forward-auth proxy, and admins always keep a password fallback. The apps sign in through the browser and receive a device token you can revoke at any time. Share links can have a password and an expiry date, and you can revoke them; admins see all links. HTTPS is automatic with the bundled Caddy.
